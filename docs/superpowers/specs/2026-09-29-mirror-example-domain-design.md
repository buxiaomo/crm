# CRM 示例域名统一设计

## 目标与范围

仓库内所有 CRM 服务地址统一使用 `mirrors.example.com`。
覆盖首页中的 Docker、Containerd 和前向代理示例，README、Caddy、Nginx，
以及历史设计文档中的 CRM URL；Nginx 证书目录同步使用该域名。

Docker/GHCR 等真实上游、认证与 CDN 主机、外部项目及参考链接保持原用途。
测试中的允许/拒绝主机、Docker 宿主别名、localhost 和回环 IP 保持原值。
这些地址不是 CRM 的对外域名，替换会改变路由、安全校验或测试含义。

## 实现与验证

直接修改现有字符串；保留 URL 协议、端口、路径、参数和凭据占位符。
不增加配置项、域名替换框架或重复配置，不修改代理逻辑和 API。
现有首页明确提示将示例域名替换为实际地址；域名、DNS 和 HTTPS 证书的部署
不属于本次仓库文本修改。

扫描全部受版本控制的文本，确认旧 CRM 地址及部署占位符已清除。
运行现有 Go 测试，再用真实本机进程通过 Unix socket 检查首页地址，
分别覆盖匿名模式和启用认证模式；所有出站上游与既有测试保持不变。
这是字符串与部署示例修改，不新增单元测试或 Docker 测试环境。
