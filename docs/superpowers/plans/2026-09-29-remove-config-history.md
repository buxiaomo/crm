# 删除本地配置历史：设计与实施计划

## 目标与边界

从全部本地分支、标签及本地快照中移除根 `config.yaml`，并清理其旧名称 `crm.yaml`。
保留 `config.example.yaml`、所有工作目录的本地配置及其他未提交内容。
远程仓库不在本次写入范围；推送须另行授权。

- [x] 仅移除各 worktree 的配置索引项，保留磁盘文件；更新旧伪引用并清理 reflog。

## 远端基线

开始操作时，远程仅有 `main` 分支，指向
`01d0914262c094b05b23cfa23bac7833f3cd15da`，没有标签。
远端更新如获授权，应使用针对该 SHA 的 `--force-with-lease`，
不能直接覆盖后来新增的提交；此前不要 fetch 以免重新引入旧历史。
最终复查发现后台 `fetch origin` 已重新下载旧历史，因此本地增加临时负向 refspec
`remote.origin.fetch = ^refs/heads/main`，阻止普通 fetch 再次拉取远程旧 main。
远程完成清理后，用 `git config --unset-all --fixed-value remote.origin.fetch '^refs/heads/main'`
恢复正常拉取；手动指定 refspec 仍可能绕过此限制。
